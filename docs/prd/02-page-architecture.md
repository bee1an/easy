# 页面架构

## 页面结构

```
/splash    - 启动页
/auth      - 登录页
/home      - 首页（快捷按钮 + 周报告）
/stats     - 统计页（详细数据分析）
/poop      - 排便模块详情（日历热力图 + 点击弹窗）
/settings  - 设置页（模块入口 + 系统设置）
```

## 首页设计

**定位**：数据分析报告 + 功能快捷入口

```
┌─────────────────────────────┐
│  快捷按钮区                   │
│  [排便] [饮食*] [运动*]       │  ← 点击直接开始记录
├─────────────────────────────┤
│                             │
│  周报告（图表形式）           │  ← 每周数据汇总
│  - 各模块趋势图表             │
│  - 关键指标可视化             │
│                             │
└─────────────────────────────┘

* 后续扩展模块
```

| 元素 | 说明 |
|-----|------|
| 快捷按钮 | 各模块入口，点击直接开始记录（如排便计时） |
| 周报告 | 图表展示最近一周各模块数据汇总 |

## 统计页

**入口**：设置页 → 统计

**内容**：
- 详细的数据分析和图表
- 长期趋势展示
- 各模块统计汇总

## 模块详情页

**入口**：设置页 → 各模块入口

**排便模块详情页 (/poop)**：
- 日历热力图（月度视图）
- 点击日期弹窗查看当日记录
- 支持编辑和删除记录

## 设置页

```
设置页
├── 模块管理
│   ├── 排便记录 → /poop（日历+记录详情）
│   ├── 饮食记录* → /diet
│   └── 运动记录* → /exercise
├── 数据
│   └── 统计分析 → /stats
├── 社交
│   └── 好友/分享
├── 账户
│   ├── 云同步状态
│   └── 退出登录
├── 外观
│   └── 深色模式
└── 关于
    └── 版本信息
```

## 页面变更对比

| 原结构 | 新结构 | 说明 |
|-------|-------|------|
| 首页：统计卡片 + 日历 | 首页：快捷按钮 + 周报告 | 首页聚焦快速操作和整体概览 |
| 历史页 | **移除** | 日历弹窗已满足需求 |
| 设置页：统计 + 设置混合 | 设置页：模块入口 + 设置 | 统计独立，设置更清晰 |
| 无独立统计页 | **新增**：统计页 | 详细数据分析 |
| 日历在首页 | 日历移至模块详情页 | 首页不再绑定单一模块 |
