# 产品概述

## 产品定位

**Easy**（暂定名）是一款综合健康追踪应用，帮助用户通过记录和回顾健康数据，更好地了解自己的身体规律和状态。

## 模块规划

| 模块 | 状态 | 说明 |
|-----|------|------|
| 排便记录 | ✅ 当前 | 首个核心模块 |
| 饮食记录 | 📋 规划中 | 后续扩展 |
| 运动记录 | 📋 规划中 | 后续扩展 |

> 架构设计需预留多模块扩展性

## 目标用户

| 阶段 | 用户群体 | 说明 |
|-----|---------|------|
| 内测阶段 | 小范围测试用户 | 验证核心功能和用户体验 |
| 正式阶段 | 关注健康的用户 | 想通过数据量化了解自己的人群 |

## 发布渠道

| 阶段 | 渠道 | 说明 |
|-----|------|------|
| 内测阶段 | SideStore 侧载 | 仅限测试用户 |
| 正式阶段 | App Store | 待定 |

## 核心价值

| 价值主张 | 说明 |
|---------|------|
| 自我了解 | 通过数据了解身体规律 |
| 简单记录 | 一键开始，快速完成 |
| 数据可视化 | 图表直观展示趋势 |
| 社交共享 | 与好友互相了解健康状况 |
