## 项目概述

**Easy** 是一款综合健康追踪应用，当前已实现排便记录模块的基础功能，后续将扩展饮食与运动模块。  
内测阶段通过 SideStore 侧载发布，正式阶段计划上架 App Store。

## 需求范围与排除项

### 需求范围
- 首页重构（快捷按钮 + 周报告）
- 统计页（新增）
- 模块详情页（排便）
- 设置页结构优化（模块入口、统计入口、社交区域）
- UI/UX 改进（玻璃拟态、动画、对话框、日历格子）

- 设置页统计卡片

## 技术要点

### 新增依赖
```yaml
dependencies:
  fl_chart: ^0.68.0
```

### Supabase 迁移
```sql
-- 已应用的迁移:
-- 20260118093310_create_follows_table
-- 20260118093331_create_follow_functions  
-- 20260118093353_add_mutual_follow_rls_for_records
```

### 数据模型与扩展性
- 确保 `HealthRecord` 抽象不与具体模块强耦合
- 新增模块时只需新增 Provider + UI 组件，首页自动适配

### 权限与数据隔离
- 记录表与分享关系启用 RLS
- 互关关系变更后立即失效，避免缓存泄露
