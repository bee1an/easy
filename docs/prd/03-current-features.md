# 现有功能清单

## 核心记录功能（排便模块）

| 功能 | 描述 | 实现状态 |
|-----|------|---------|
| 计时记录 | 点击「记录」开始计时，再次点击结束并填写详情 | ✅ 已完成 |
| 布里斯托分级 | 支持 1-7 型标准分类 + 自定义输入 | ✅ 已完成 |
| 量记录 | 少量 / 正常 / 大量 + 自定义 | ✅ 已完成 |
| 颜色记录 | 正常 / 自定义 | ✅ 已完成 |
| 时间编辑 | 可手动调整开始/结束时间 | ⚠️ 仅支持时间，待支持日期 |
| 记录编辑 | 可修改已保存的记录 | ✅ 已完成 |
| 记录删除 | 带确认的删除功能 | ✅ 已完成 |

## 数据展示功能

| 功能 | 描述 | 状态变更 |
|-----|------|---------|
| 日历热力图 | 月度视图，颜色深浅表示当日次数 | ✅ 移至模块详情页 |
| 日详情弹窗 | 点击日历某天查看当日所有记录 | ✅ 保留 |
| 统计卡片（首页） | 连续天数、今日次数、本月次数 | ❌ 移除，改为周报告 |
| 统计卡片（设置页） | 总记录数、当前连续、最长连续 | ❌ 移除，移至统计页 |
| 历史列表页 | 按时间倒序显示所有记录 | ❌ 移除 |

|-----|------|---------|

| 云端存储 | 记录直接存储到 Supabase | ✅ 已完成 |
